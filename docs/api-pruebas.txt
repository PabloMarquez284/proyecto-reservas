# Pruebas de la API (contenedor reservas_api) - 02/10/2026"

## 1. Usuario con el que corre la API (debe ser node, no root)
$ docker compose exec api whoami
node

## 2. Estado de la API
$ wget http://localhost:3000/api/health
{"estado":"ok"}

## 3. Crear una reserva (POST)
$ wget --post-data=... http://localhost:3000/api/reservas
{"id":2,"actividad":"Concierto en el Maestranza","nombre":"Pablo","fecha":"2026-10-15T00:00:00.000Z"}

## 4. Listar reservas (GET)
$ wget http://localhost:3000/api/reservas
[{"id":1,"actividad":"Visita a la Catedral","nombre":"Pablo","fecha":"2026-10-10T00:00:00.000Z"},{"id":2,"actividad":"Concierto en el Maestranza","nombre":"Pablo","fecha":"2026-10-15T00:00:00.000Z"}]
